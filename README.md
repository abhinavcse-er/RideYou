# RideYou

A mobile-first ride booking platform for Bihar.

## Stack
- React + Vite frontend
- Node.js + Express API
- Supabase PostgreSQL database

## Project status
Initial repository setup. Booking flow, admin/driver dashboards, fare approval, secure driver assignment, and in-app communication will be delivered in milestones.

## Security principles
- No public admin registration.
- Driver personal phone numbers are not exposed to customers.
- Customer booking data is private.
- Keep service-role keys server-side and out of Git.
- Free hosting tiers are not a 24/7 reliability guarantee.
